# Routing Rules / 路由规则

| Signal | Route | Reason |
|---|---|---|
| 单一岗位、一次性、小范围 | 专业员工 | 最短路径、最低成本 |
| 一个长期项目、多个岗位 | 项目主管 | 统一上下文和依赖 |
| 多项目、优先级或预算冲突 | CEO | 需要全局决策 |
| 成品、上线、公开发布 | 负责人 + 独立验收 | 结果可复核 |
| 任务互不依赖 | 并行派发 | 缩短等待 |
| 需要用户偏好或公开口径 | 先交方案 | 用户确认后再制作 |

升级条件：权限/路径阻塞、范围变化、质量门禁连续失败、跨项目依赖或需要用户决策。没有升级条件时，员工在原岗位内闭环。
