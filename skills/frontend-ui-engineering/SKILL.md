# Frontend UI Engineering

Inspect the existing visual system before adding components. Define responsive
layout constraints, loading/error/empty states, keyboard access, and readable
focus states. Keep interaction state explicit and verify the target viewport
with a real browser or rendered preview. Do not call a static screenshot a
working UI.
