# Context Engineering

Keep company rules, project context, and task history in separate layers.
Load stable context once, then pass only changed conclusions, evidence, risks,
and next actions. Preserve long-running employee memory by reference instead
of copying full conversations. Remove stale paths and assumptions from the
active context after the task is closed.
