# Debugging And Error Recovery

Capture the exact error and environment, reproduce it, localize the failing
boundary, and reduce to the smallest failing case. Apply one focused fix,
rerun the reproduction and regression suite, then record root cause and
rollback. Do not repeat an unchanged failing attempt.
