# Planning And Task Breakdown

Separate discovery, implementation, verification, and delivery. Give every
task one owner, one output, and one measurable acceptance check. Mark
dependencies explicitly; independent tasks may run in parallel. Keep each
handoff to conclusions, evidence, risks, and next action. Do not start work
until the plan exposes irreversible or high-cost steps for confirmation.
