# Task Card / 任务卡

```yaml
id: TASK-YYYYMMDD-###
title: ""
project: ""
goal: ""
success_criteria:
  - ""
owner: ""
collaborators: []
route: direct_worker | project_lead | ceo
inputs: []
constraints: []
deliverables: []
dependencies: []
approval_required: false
status: todo | in_progress | waiting | review | done | rework
deadline: ""
budget:
  max_tool_calls: null
  max_rounds: null
acceptance:
  reviewer: ""
  checks: []
next_action: ""
```

填写原则：一项任务一个负责人；成功标准必须可观察；将“方案”和“制作”拆开；没有依赖的子任务并行。
